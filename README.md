# StudyFlow – Mobile Programming Project

**Team:** 6  
**Course:** MTM4186 – Mobile Programming  
**Project:** StudyFlow

## Project Overview

StudyFlow is a mobile application designed to help students organize their study schedules, manage tasks, and track their study progress.

## Technologies and Tools

- **Flutter** – Mobile application development
- **Dart** – Programming language used with Flutter
- **Figma** – User interface design and prototyping
